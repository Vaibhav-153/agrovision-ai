# Dataset notes

The training record available with this project describes an object-detection dataset with about 1,300 images and two classes: `crop` and `weed`.

The public repository does not contain the training dataset. It also does not record the original dataset URL, dataset license, train/validation/test counts, or exact preprocessing and augmentation settings. Those details are therefore not stated as facts in the README or model card.

For a reproducible retraining workflow, the missing dataset source and split information should be recorded before new training results are published.
