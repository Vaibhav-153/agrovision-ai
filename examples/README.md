# Example Images

- `crop_example.jpeg`: image whose dataset annotation contains crop objects.
- `weed_example.jpeg`: image whose dataset annotation contains a weed object.
- `mixed_example.jpeg`: more complex image containing both class IDs in the source annotation.

These files are included only for demonstration and testing of the user interface. The exact hosted-model output depends on thresholds and current provider behavior. No prediction JSON is pre-filled because live private-model inference was not available in the build environment.
