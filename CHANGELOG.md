# Changelog

## 1.0.0 — 2026-08-09

- Added a production-style Gradio interface for crop and weed detection.
- Integrated the private Roboflow-hosted YOLO11 Nano model.
- Added strict image validation, EXIF removal, class mapping, bounding-box rendering, and normalized JSON output.
- Added GitHub Actions, Docker support, Hugging Face configuration, tests, study documentation, viva questions, and deployment runbooks.
- Deliberately omitted local training code because the model was trained and is served on Roboflow.
