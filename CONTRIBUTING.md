# Contributing

1. Create a branch from `main`.
2. Keep secrets out of commits and screenshots.
3. Add or update tests for behavior changes.
4. Run `python -m compileall -q app.py src scripts tests` and `python -m pytest`.
5. Update the documentation when configuration, metrics, or deployment steps change.
6. Open a pull request describing the problem, implementation, and verification performed.

Model-performance claims must be backed by saved evaluation output. Do not replace unavailable metrics with estimates.
